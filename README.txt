DECKER STOCK ONLINE
===================

Este paquete contiene una web estática estilo marketplace para Decker Camiones.

Archivos:
- index.html: estructura de la página.
- styles.css: diseño visual responsive.
- script.js: stock de unidades, filtros, simulador de financiación y formularios por WhatsApp.

Cómo usar:
1. Descomprimir el ZIP.
2. Abrir index.html en el navegador.
3. Para cambiar unidades publicadas, editar el array "units" dentro de script.js.
4. Para cambiar teléfonos de WhatsApp, editar "agencyPhones" dentro de script.js.
5. Para subir a internet, enviar la carpeta a un hosting o a quien administre la web.

Nota:
La web es estática. Los formularios no guardan datos en una base: generan una consulta por WhatsApp.
Para un sistema completo tipo Kavak se necesitaría backend, panel administrador, base de datos, carga de fotos y dominio/hosting.
